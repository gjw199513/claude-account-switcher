# Claude アカウント切替

Claude Desktop の複数アカウントを切り替え、ローカルの Code セッション一覧を引き継ぐシンプルな非公式 macOS アプリです。各アカウントに個別にログインし、同時に使う Claude ウィンドウは一つです。

## インストール

macOS、`/Applications` にある Claude Desktop、Xcode Command Line Tools、`/usr/bin/python3` 3.9 以降が必要です。

```sh
git clone https://github.com/gjw199513/claude-account-switcher.git
cd claude-account-switcher
./install.sh
```

`~/Applications` から **Claude Account Switcher** を開きます。画面はシステム言語に合わせて、英語、簡体字中国語、日本語、韓国語、スペイン語、フランス語、ドイツ語を表示します。

## 使い方

1. 現在の Claude は**アカウント A**です。**アカウントを追加**を押し、切り替えを確認して、新しい Claude ウィンドウでログインし、**Code** を開きます。
2. 初回は Claude を `⌘Q` で終了し、そのアカウントを選んでもう一度**切り替え**を押して、共有セッション一覧を読み込みます。
3. 以後はアカウントを選んで**切り替え**を押します。現在の Claude を正常終了し、ローカル索引を自動的に同期して、選択したアカウントを開きます。実行中の作業は先に完了または保存してください。

同じ方法で追加できます。ログイン期限が切れた場合は再ログインが必要です。

## 仕組みと制限

- 各アカウントの Claude データディレクトリは独立しています。ログインは Claude が処理し、このツールは認証情報を取り出したりコピーしたりしません。プロキシや利用枠による自動切替もありません。
- Code のローカル本文は `~/.claude/projects` を共有し、アカウント別サイドバー索引をバックグラウンドと切替時に同期します。反映には Claude の再起動が必要な場合があります。
- クラウドチャット、Cowork、利用枠、アカウント固有のコネクタ、Desktop 固有の設定は共有しません。
- SSH、WSL、カスタム worktree などの特殊または未対応のセッションはスキップされる場合があります。既存の一時ワークスペースは元のパスを使用するため、そのプロファイルを削除すると開けなくなる場合があります。組織フォルダーが複数ある場合は推測せず同期を停止します。
- 競合や不正な索引は保持し、上書き前にバックアップします。削除は他のアカウントへ伝播しません。Claude Desktop の非公開形式に依存するため、更新後に動作しなくなる可能性があります。

**検証:** 現在の Mac で、アカウント B に A の Code サイドバーが表示されることを確認しました。複数アカウントの同期と安全処理は模擬テスト済みですが、実際の会話の継続や他の Claude バージョンは未検証です。

## アンインストール

`./uninstall.sh` を実行します。Claude のプロファイル、会話、ローカルバックアップは残ります。
