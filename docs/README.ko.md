# Claude 계정 전환

Claude Desktop의 여러 계정을 전환하면서 로컬 Code 세션 목록을 유지하는 간단한 비공식 macOS 앱입니다. 각 계정은 별도로 로그인하며 한 번에 하나의 Claude 창만 사용합니다.

**사용량 검증 상태:** 모의 암호화 데이터와 응답을 테스트했습니다. 실제 계정의 키체인 승인과 온라인 조회는 아직 검증하지 않았습니다.

## 설치

macOS, `/Applications`에 설치된 Claude Desktop, Xcode Command Line Tools, `/usr/bin/python3` 3.9 이상이 필요합니다.

```sh
git clone https://github.com/gjw199513/claude-account-switcher.git
cd claude-account-switcher
./install.sh
```

`~/Applications`에서 **Claude Account Switcher**를 실행하세요. 인터페이스는 시스템 언어에 따라 영어, 중국어 간체, 일본어, 한국어, 스페인어, 프랑스어, 독일어로 표시됩니다.

오른쪽 위 메뉴에서 언어를 직접 선택하거나 시스템 설정을 따를 수 있습니다. 사용량을 읽으려면 계정을 선택하고 **새로고침**을 누르세요. 처음에는 용도를 설명하며 macOS가 키체인의 Claude Safe Storage 접근을 요청할 수 있습니다. Claude Desktop의 기존 로그인을 사용하므로 별도 로그인이나 모델 메시지는 필요하지 않습니다. 액세스 토큰은 메모리에서 잠시 복호화하여 HTTPS로 `api.anthropic.com`에만 보내며 저장·기록·갱신하지 않습니다. 처음 성공한 뒤 macOS 로그인 중 약 15분마다 조회하고 수동 갱신은 5분 간격입니다. 30분이 지난 값이나 초기화 시각이 지난 값은 숨깁니다. 비활성 계정의 토큰이 만료되면 Claude에서 해당 계정을 열어 갱신해야 할 수 있습니다. 저장 형식과 사용량 API는 비공개이며 변경되거나 제한될 수 있습니다.

## 사용 방법

1. 현재 Claude는 **계정 A**입니다. **계정 추가**를 누르고 전환을 확인한 뒤 새 Claude 창에서 로그인하고 **Code**를 엽니다.
2. 처음 로그인한 후 Claude에서 `⌘Q`로 종료하고 해당 계정을 선택해 **전환**을 다시 눌러 공유 세션 목록을 불러옵니다.
3. 이후에는 계정을 선택하고 **전환**을 누르면 됩니다. 현재 Claude를 정상 종료하고 로컬 인덱스를 자동으로 동기화한 다음 선택한 계정을 엽니다. 전환 전에 진행 중인 작업을 완료하거나 저장하세요.

같은 방법으로 계정을 더 추가할 수 있습니다. 로그인이 만료되면 다시 로그인해야 할 수 있습니다.

## 동작 방식과 제한

- 각 계정은 별도의 Claude 데이터 폴더를 사용합니다. 전환할 때 자격 증명을 이동하거나 변경하지 않으며, 사용량 조회 시에만 위에 설명한 방식으로 토큰을 사용합니다. 사용량에 따른 자동 전환은 없습니다.
- 로컬 Code 대화 내용은 `~/.claude/projects`를 공유합니다. 백그라운드 작업과 전환 과정에서 계정별 사이드바 인덱스를 동기화합니다. 목록을 다시 읽으려면 Claude를 재시작해야 할 수 있습니다.
- 클라우드 채팅, Cowork, 계정 사용량, 계정별 커넥터와 Desktop 전용 설정은 공유하지 않습니다.
- SSH, WSL, 사용자 지정 worktree 등 특수하거나 인식하지 못하는 세션은 건너뛸 수 있습니다. 기존 임시 작업 공간은 원래 경로를 사용하므로 해당 프로필 폴더를 삭제하면 열 수 없게 될 수 있습니다. 조직 폴더가 여러 개이면 추측하지 않고 동기화를 중지합니다.
- 충돌하거나 잘못된 인덱스는 보존하며 덮어쓰기 전에 백업합니다. 삭제는 다른 계정에 전파되지 않습니다. Claude Desktop의 비공개 저장 형식에 의존하므로 업데이트 후 동작하지 않을 수 있습니다.

**검증:** 현재 Mac에서 계정 B에 A의 로컬 Code 사이드바가 표시되는 것을 확인했습니다. 다중 계정 동기화와 안전 처리는 모의 테스트를 통과했으며, 실제 대화 이어가기와 다른 Claude 버전은 아직 완전히 검증하지 않았습니다.

## 선택 사항: 로컬 예약 준비

[Claude Code CLI](https://code.claude.com/docs/en/setup) 2.1.268 이상을 설치하세요. 계정을 선택하고 준비 설정에서 공식 CLI 로그인을 완료한 뒤 새로고침하고 표시된 이메일을 확인하여 시간과 사용 여부를 설정합니다. 계정별 CLI 설정은 분리되며 앱은 인증 정보를 읽지 않습니다.

macOS에 로그인되어 있으면 창을 닫아도 짧은 Haiku 요청을 보냅니다. 절전 또는 종료로 놓치면 당일 나중에 앱을 열 때 전송 여부를 묻습니다. 실패한 요청은 당일 자동 재시도하지 않습니다. 사용량을 소비하며 추가 요금이 발생할 수 있고 새 5시간 창 시작은 보장되지 않습니다.

## 제거

`./uninstall.sh`를 실행하세요. Claude 프로필, 대화 및 로컬 백업은 유지됩니다.
