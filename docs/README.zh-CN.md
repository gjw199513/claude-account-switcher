# Claude 账号切换

一个简洁的非官方 macOS 工具，用于切换 Claude 桌面端的多个账号，并保留本地 Code 会话列表。每个账号单独登录，同一时间只运行一个 Claude 窗口。

**验证状态：**额度展示与桌面登录复用已在本机检查，定时执行、防重复发送与运行隔离通过自动化测试；真实预热消息发送及其对额度窗口的影响仍待验证。

## 安装

需要 macOS、安装在 `/Applications` 的 Claude Desktop、Xcode 命令行工具，以及 `/usr/bin/python3` 3.9 或更新版本。在终端执行：

```sh
git clone https://github.com/gjw199513/claude-account-switcher.git
cd claude-account-switcher
./install.sh
```

从 `~/Applications` 打开 **Claude Account Switcher**。界面跟随系统语言，支持简体中文、英语、日语、韩语、西班牙语、法语、德语。

右上角的语言菜单可以手动选择语言，或跟随系统。要读取额度，选择账号并点击**刷新**。首次读取会说明用途，macOS 可能要求允许访问钥匙串中的 Claude Safe Storage。工具复用该账号在 Claude Desktop 的已有登录，无需为额度再次登录，也不发送模型消息。它仅在内存中临时解密桌面端访问令牌，通过 HTTPS 发送给 `api.anthropic.com` 查询额度；不会保存、记录或刷新凭据。首次成功后，打开切换器、回到窗口或选择账号时自动检查，macOS 登录期间约每 5 分钟刷新一次；冷却期内复用最近结果，也保留手动刷新。两项额度均显示接口返回的具体重置日期和时间（本地时区）；未返回时间时如实提示，过期数据等待刷新。进度条显示最近读取的 5 小时和每周已用百分比，不是 Token 数量；超过 30 分钟或已过重置时间的数值会隐藏。未运行账号的令牌可能过期，需要在 Claude 中打开该账号以更新登录。桌面端存储格式及额度接口并非公开协议，可能变化或受到限流。

## 使用

1. 当前 Claude 配置为**账号 A**。点击**添加账号**，确认切换，在 Claude 窗口中登录新账号并打开 **Code**。
2. 首次登录后，在 Claude 中按 `⌘Q` 退出，再选择该账号并点击**切换**一次，让共享会话列表加载。
3. 以后从列表选择账号并点击**切换**即可。工具会正常关闭当前 Claude、自动处理本地会话索引，再打开选中的账号。切换前请先完成或保存正在运行的工作。

其他账号可以按同样方式添加。登录过期时，仍可能需要重新登录。

## 原理与限制

- 每个账号使用独立的 Claude 数据目录。切换时不会移动或替换凭据；额度读取会按上文说明使用桌面端令牌。工具不会根据额度自动切换账号。
- 本地 Code 会话正文共用 `~/.claude/projects`；后台任务和切换过程会自动合并按账号区分的侧边栏索引。Claude 可能需要重启才会重新加载列表。
- Claude 云端普通聊天、Cowork、账号额度和云端连接器保持独立。桌面端独立设置也不会自动合并。
- SSH、WSL、自定义 worktree 等特殊或无法识别的会话可能被跳过。已有临时工作区保留原路径，删除其所属账号目录可能导致会话无法打开。发现多个组织目录时，工具会暂停自动同步，不猜测目标。
- 冲突或格式异常的记录会保留，覆盖前会备份目标索引；删除操作不会传到其他账号。本工具依赖 Claude Desktop 未公开的内部存储结构，客户端更新后可能失效。

**验证情况：**本地 Code 侧边栏合并已在 macOS 上检查，多账号合并和安全处理通过模拟测试。真实会话跨账号续接及其他 Claude 版本尚未全部验证。


## 卸载

运行 `./uninstall.sh`。Claude 账号目录、会话和本地备份会保留。

## 额度预热

选择账号，点击**设置**，开启每日定时预热并选择本地时间；也可以直接点击**立即预热**。定时默认关闭，每个账号独立设置。电脑需保持唤醒，休眠错过后跳过，可手动补发。

预热复用所选账号在 Claude Desktop 中已有的登录和已下载的官方运行组件，不再要求单独登录 CLI。登录令牌只在短时运行的官方进程环境中使用，不写入配置、日志或状态文件；临时工作目录运行后清理。不会加载项目文件、工具、插件或用户脚本。

每次发送一条 Haiku 短消息，会消耗少量额度；已知额度用尽时不会发送。定时失败当天不自动重试。窗口是否开启、何时重置，以 Claude 返回为准，不保证提前开启新窗口。桌面登录过期时，在 Claude 中打开对应账号更新登录即可。
