# Design direction

A restrained desktop instrument panel with the warmth of Claude's visual language. The app is an independent project: it does not use Anthropic's logos or claim affiliation.

The palette is informed by the independently documented [Claude design reference](https://www.designmd.run/design/claude.ai), adapted for a dark macOS window:

- Background: `#141413`; raised surfaces: `#1F1E1D` and `#2A2724`.
- Main text: `#FAF9F5`; secondary text: `#B0AEA5`.
- Primary accent: `#D97757` (clay); caution uses a lighter warm tone.
- The icon uses original opposing arrows, on an ivory `#F5F0E8` tile.

Use system sans-serif for interface text and the system monospaced face sparingly for account identifiers and timestamps. Keep progress bars horizontal, spacing generous, and outlines quiet. Short cut corners give the account panels an instrument-like character without imitating official brand marks.
